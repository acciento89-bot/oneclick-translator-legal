FAQ

Common questions.

Does the bot translate every message automatically?

No. A member actively clicks Translate, which avoids unnecessary API usage and channel spam.

Can other members see my translation?

No. The result is delivered as a private Discord interaction response visible only to you.

Who configures the translation channels?

A server administrator chooses the channels with /setup add. Members only need /language.

How is Premium purchased?

Premium is purchased and managed through Discord. Run /premium after installing the app.

Where can I get help?

Use /report-issue inside Discord, open the contact form, or join the support server.
